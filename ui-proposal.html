Design Principles Applied

Typography

  • Body font (Inter): Reduces cognitive load, excellent at small sizes
  • Display font (Merriweather): Serif for h1-h3 and nav brand only - adds authority without distraction
  • Base size 15px: Slightly larger than typical 14px - more readable for long sessions
  • Clear hierarchy: Font, weight, and size work together - no guessing

Colors

  • Army green primary: (#556B2F) for nav and all concept references
  • Consistent color coding: Every mention of a concept/source/person/tag uses its semantic color
  • Green: Concepts - everywhere they appear (badges, links, filters)
  • Slate blue: Sources - darkened to #2d5466 for WCAG AA contrast
  • Brass/gold: People/authors - darkened to #a67c2e for contrast
  • Plum: Tags - muted purple (#674675)

Layout & Spacing

  • 4px base unit: Consistent rhythm throughout
  • Subtle rounding: 4px for cards/buttons, 2px for small elements, pill (9999px) for bold badges
  • More whitespace: Easier scanning, less overwhelming
  • Depth through shadows: Subtle layering instead of flat borders

Interaction

  • Obvious affordances: Buttons look like buttons
  • Clear hover states: Background changes, no guessing
  • Active indicators: Pills for filters, highlighted nav
  • Smooth transitions: 150ms for responsive feel
  • FontAwesome icons: Theme color on light, white on dark
  • Themed checkboxes: Accent color matches primary

Key Usability Improvements

  1. Colored nav: Army green with subtle outline button - clear branding without screaming
  2. Depth through shadows: Strong inset shadow on sidebar, no borders - clean layering
  3. White card headers: Removed gray tint - one less color to parse
  4. Consistent color coding: Every concept is green, source is blue, person is gold, tag is purple - everywhere
  5. Color-coded filter pills: Active filters use semantic colors - instantly scannable
  6. WCAG AA compliant: Darkened brass and slate for proper contrast on light backgrounds
